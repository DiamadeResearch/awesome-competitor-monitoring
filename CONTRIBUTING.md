# Contributing

Contributions welcome! Please:

1. Search existing resources to avoid duplicates
2. One resource per pull request
3. Include a brief description
4. Follow the existing format: `- [Name](URL) — Description.`
5. Mark free/open-source tools with `[Free]`

## Awesome List Guidelines

- Must be directly relevant to competitor monitoring or competitive intelligence
- Tools should be actively maintained
- Prefer open source, but commercial tools are welcome
- No affiliate or referral links
